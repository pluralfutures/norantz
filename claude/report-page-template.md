# Norantz report page template

Version 0.1, 16 November 2026. Draft for review.

This is the fill-in skeleton for the public page of one reviewed report. The reasons behind each section are in `report-page-spec.md`.

## How to use it

- Replace text in [brackets]. Remove every line that starts with "Note:".
- Keep all sections, in this order. If a section does not apply, keep the heading and use the fallback line given.
- Word limits are ceilings.
- Write for a reader who has not seen the report. Use the report's own terms for its scenarios and targets, and plain words for everything else.
- Describe what the evidence shows. Do not write "wrong", "failed" or "missed" about the report or its authors.
- Rating scales marked "proposed" are not yet agreed.

## 2. How to read this page

Note: fixed text on every page. Only the last paragraph changes.

Scenarios are not predictions. They describe different ways the future could unfold, so that today's decisions can be tested against them.

This page does not grade the report. It shows which of the report's assumptions the evidence supports so far, and which deserve a second look.

| Rating | Meaning |
| --- | --- |
| Confirmed | Evidence matches the report. |
| Strengthened | Evidence goes further in the same direction. |
| Weakened | The direction holds, but the size or timing does not. |
| Invalidated | Evidence contradicts the report. |
| Not yet reviewed | Not yet testable, or not yet checked. |

[One sentence on what this report type allows. For quantified scenarios: "This report gave numbers for each scenario, so we compare them with published figures." For narrative scenarios: "This report told stories without numbers, so we look for signs that each story is unfolding."]
