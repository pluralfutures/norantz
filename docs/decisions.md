# Decisions

Every significant decision made in the claude.ai project "NBD-Norantz" between 16 and 17 November 2026, with the reason and the options set aside. Written 18 November 2026.

**Status labels used below**

- **Confirmed**: the owner chose it or said so explicitly. Do not reopen without asking.
- **Adopted**: written into a method or spec doc and used in the work; the owner approved the step but did not rule on the point itself.
- **Proposed**: a default in a doc that has not been agreed. Listed here because later work already depends on it. Open versions are in `open-questions.md`.

"Rejected" means an option that was put to the owner and not chosen, or one the work considered and set aside for a stated reason. Where no reason was recorded, the entry says so.

## 4. Review method (`claude/scenario-review-method.md`, v0.2)

## 10. Things we said no to (one list)

- Traffic-light status colours; damped semantic colours; one ink per status.
- Overall scores, percentages, grades, report cards, filling bars, ticks and crosses.
- "Invalidated" on the public page (register keeps it; public label proposed as "Not supported so far").
- Ember in data or status; more than one call to action per screen.
- The spectrum behind text, on a vision page or in a status marker.
- Gradients other than the spectrum; blur; noise; glass; drop shadows on cards.
- Photographs of politicians or officials; stock or AI-slick imagery.
- Emoji; exclamation marks; the banned words (*innovate, leverage, unlock, transform, ecosystem, disrupt, game-changer, robust, shocking, damning, slammed, reality check, scorecard, verdict, report card, fact-check*).
- "Failed", "missed", "wrong", "ignored", "overlooked", "outdated", "threat" about a report or its authors.
- NORANTZ in caps in running text; "Nora" as a short form; NorantzCheck-style compounds; setting the wordmark in a font; PF's eye, dots or chevron as Norantz's mark.
- Body text in Bricolage, headings in Newsreader, more than one sentence in Mono, left rules except for report quotes.
- Media as evidence for a rating.
- Citing the Indonesian draft annex; rating "~" values; rating against projected 2025 baselines when outturns exist; keynote figures as evidence.
- Drawing projected evidence lines on charts.
- Naming a single closest scenario when the elements disagree.
- Classifying a report from secondary descriptions.
